# 🚀 Innovest – Idea Investing App

Innovest is a mobile application where users can **share startup ideas, invest virtual coins, and track portfolio growth**.
It combines social interaction with investment simulation to create a fun and engaging platform for innovation.

---

## ✨ Features

* 💡 **Post Ideas** – Share your startup ideas with title, problem & solution
* ❤️ **Like System** – Users can like ideas
* 💰 **Invest Coins** – Invest virtual coins in ideas
* 📊 **Portfolio Tracking** – Track total investment and earnings
* 📈 **Analytics Graph** – Visualize investment trends
* 💬 **Comments** – Interact with other users (Insta-style UI)
* 🏆 **Leaderboard** – Top ideas & investors ranking
* 🔍 **Search** – Find ideas easily
* 🔥 **Trending Badge** – Highlight popular ideas

---

## 🛠️ Tech Stack

* **Frontend:** React Native (Expo)
* **Backend:** Firebase (Firestore + Auth)
* **Database:** Cloud Firestore
* **Charts:** react-native-chart-kit

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/Naincy33/innovest.git
cd innovest
```

2. Install dependencies:

```bash
npm install
```

3. Start the app:

```bash
npx expo start
```

---

## 🔐 Environment Setup

Create a `.env` file and add your keys:

```env
OPENAI_API_KEY=your_api_key_here
```

⚠️ Do not commit `.env` file to GitHub.

---

## 📊 Firebase Setup

* Create a Firebase project
* Enable **Authentication (Email/Password)**
* Enable **Firestore Database**
* Add your Firebase config in `firebase.js`
